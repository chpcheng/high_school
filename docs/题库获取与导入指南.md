# 题库获取与导入指南

> 面向「高中刷题小程序」的题库数据准备与导入说明。
> 技术栈：微信云开发（云数据库 / 云函数），题库存储于 `questions` 集合。

---

## 一、题库数据模型（导入前必读）

题目存放在云数据库 `questions` 集合，字段结构如下（详见 `DESIGN.md` 第四章）：

| 字段 | 类型 | 说明 |
|---|---|---|
| `subjectId` | string | 所属学科 `_id`（关联 `subjects`） |
| `knowledgePointId` | string | 所属知识点 `_id`（关联 `knowledge_points`） |
| `difficulty` | number | 难度：1=简单 2=中等 3=困难 |
| `type` | string | 题型：`single` 单选 / `multiple` 多选 / `fill` 填空 / `solution` 解答 |
| `stem` | string | 题干 |
| `stemImage` | string | 题干配图 URL（可选，云存储 fileID 或 https） |
| `options` | array | 选择题选项 `[{ "key": "A", "text": "…" }]`（单选/多选） |
| `answer` | object | 标准答案（按题型，见下） |
| `analysis` | string | 解题思路总述 |
| `steps` | array | 分步解析 `[{ "order": 1, "title": "…", "content": "…" }]`（核心差异点） |
| `status` | string | `published` 已发布 / `draft` 草稿 |
| `tags` / `source` / `createdBy` / `createdAt` | — | 标签、来源、创建信息（可选） |

### `answer` 结构（按题型）

```jsonc
// 单选 / 多选
{ "keys": ["A", "C"] }

// 填空（支持多空，每空多个等价答案）
{ "blanks": [["29"], ["x=1", "x = 1"]] }

// 解答题
{
  "reference": "参考答案与评分要点…",
  "keywords": ["配方", "x = 2", "1"]   // 关键词命中判分；为空则标记「待批改」
}
```

### `steps` 结构（分步解析，本项目的核心差异点）

```jsonc
[
  { "order": 1, "title": "第一步：审题转化", "content": "把…条件转化为…" },
  { "order": 2, "title": "第二步：建立方程", "content": "由…得…" },
  { "order": 3, "title": "第三步：求解", "content": "解得 x=…" }
]
```

> 关键规则：**选择题必须带 `options`**；**填空 `blanks` 每空一个数组**；**解答题带关键词才自动判分，否则进入「待批改」**。

## 二、题库获取渠道

### 1. 公开真题与教辅（最常用，注意版权合规）

- **历年高考真题 / 各省模拟卷**：教育部与各省考试院公开的历年真题（含答案与解析），是高质量、无版权争议的首选来源。
- **教材例题与课后习题**：课本例题结构清晰、难度分层明确，适合做种子题库。
- **教辅机构公开的免费题库**：部分机构提供免费公开题，使用前需确认授权范围。

> ⚠️ 版权提示：公开真题与教材例题一般可作教学用途，但商业运营前请确认题目版权授权，避免使用来源不明的扫描/爬取内容。

### 2. 教师 / 教研团队自建（推荐用于长期运营）

- 由学科教师命题，按「学科 → 知识点 → 难度 → 题型」三级分类录入。
- 优势：质量可控、可搭配 `steps` 分步解析，充分发挥本项目的差异化能力。

### 3. AI 辅助生成（提效，需人工审核）

- 用大模型（如通用对话模型）按统一 schema 生成题目初稿，再由教师审核校正。
- 重点审核：答案正确性、知识点归类、`steps` 步骤是否循序渐进、难度标注是否准确。

### 4. 第三方题库开放平台 / API

- 部分教育科技平台提供题库 API 或批量导出（通常为付费授权），适合规模化引入。
- 引入时按对方接口返回的数据，映射到本项目的 `questions` 字段结构。

## 三、如何准备题库数据

### 方式 A：修改内置种子题库（适合少量示例题）

项目已内置种子数据 `cloudfunctions/initData/seed.js`（2 门学科、5 个知识点、7 道示例题，覆盖四种题型）。

- 打开 `cloudfunctions/initData/seed.js`，仿照现有结构**追加**你的题目（`subjects` / `knowledgePoints` / `questions` 三个数组）。
- 题目用「学科名 + 知识点名」引用（如 `subject: '数学', point: '二次函数'`），`initData` 云函数会自动把它们映射为 `_id` 并写入。
- 重新部署 `initData` 云函数后，在控制台运行一次即可（幂等，已存在的数据不会重复写入；但**新增题目需先清空 questions 集合或改用方式 B**，否则因「已存在则不写入」会跳过）。

### 方式 B：批量导入 JSON（适合大量题目，推荐）

1. **准备 JSON 文件**：将题目整理为 JSON 数组，每条字段与 `questions` 结构对齐。示例：

```jsonc
[
  {
    "subjectName": "数学",
    "knowledgePointName": "二次函数",
    "difficulty": 2,
    "type": "single",
    "stem": "抛物线 y = x² − 2x + 3 的顶点坐标是（　）",
    "options": [
      { "key": "A", "text": "(1, 2)" },
      { "key": "B", "text": "(1, 4)" }
    ],
    "answer": { "keys": ["A"] },
    "analysis": "将一般式化为顶点式求解。",
    "steps": [
      { "order": 1, "title": "审题", "content": "识别 a=1,b=−2,c=3。" }
    ],
    "status": "published"
  }
]
```

2. **通过云开发控制台导入**：
   - 打开微信开发者工具 →「云开发」控制台 →「数据库」→ 选中 `questions` 集合 →「导入」，上传 JSON（**需为 JSON Lines 格式**，即每行一个 JSON 对象，或使用控制台支持的格式）。
   - 导入前需先将题目中的「学科名 / 知识点名」替换为真实的 `subjectId` / `knowledgePointId`（可在控制台查看各集合的 `_id`）。

3. **通过云函数批量写入**：在 `initData` 中新增一个读取 JSON 文件的逻辑，或编写独立导入云函数，将 JSON 解析后逐条 `add` 到 `questions`。

> 提示：大量数据（数千条）建议分批次导入，避免单次云函数超时；云数据库单次 `add` 上限为 1 条，批量请用循环或 `db.collection().add` 多次调用。

### 方式 C：用内容管理 CMS（适合非技术团队长期维护）

微信云开发提供「内容管理（CMS）」扩展，可一键部署，用可视化界面管理 `questions` 集合（增删改查、上传图片、富文本），适合教师/运营人员日常维护题库，无需写代码。

## 四、导入后的验证清单

1. **学科/知识点关联正确**：`subjectId`、`knowledgePointId` 指向的 `_id` 真实存在。
2. **题型字段一致**：选择题有 `options` 且 key 为 A/B/C/D；填空 `blanks` 为二维数组；解答题 `answer.reference` 存在。
3. **难度与状态正确**：`difficulty` ∈ {1,2,3}；`status` 为 `published` 才能被抽题。
4. **分步解析完整**：`steps` 数组非空、`order` 连续递增、`title`/`content` 齐全。
5. **抽题验证**：小程序首页 → 开始刷题 → 选择学科/知识点 → 能正常抽到新导入的题目。
6. **建议建索引**：在云开发控制台为 `questions` 建 `knowledgePointId + difficulty + status` 组合索引、`answer_records` 建 `userId + answeredAt` 组合索引（详见 `database/README.md`），保证抽题与统计查询性能。

## 五、常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 导入后抽不到题 | `status` 非 `published`，或 `knowledgePointId` 关联错误 | 检查状态与关联 `_id` |
| 解答题一直「待批改」 | `answer.keywords` 为空 | 补充关键词，或接受待批改（由教师补判） |
| 配图不显示 | `stemImage` 用了外链或非法域名 | 用云存储 fileID，或配置合法域名 |
| 题目重复 | 导入了重复 `_id` 或重复内容 | 控制台去重，或导入前按题干去重 |
