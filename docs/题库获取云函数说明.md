# 题库获取云函数（importQuestionBank）说明

> 将题库数据从数据源拉取并写入微信云开发「云数据库」的云函数。
> 云函数目录：`cloudfunctions/importQuestionBank/`

---

## 一、概览

| 项 | 说明 |
|---|---|
| 云函数名 | `importQuestionBank` |
| 职责 | 从数据源拉取题目 → 校验 → 关联学科/知识点 → 幂等写入 `questions` 集合 |
| 写入目标 | 云数据库 `questions`（自动创建缺失的 `subjects` / `knowledge_points` 记录） |
| 数据源 | ① 内置示例数据源（默认）② 任意 HTTPS/HTTP JSON 接口（传 `sourceUrl`） |
| 运行环境 | Node.js（微信云开发），仅依赖 `wx-server-sdk`，HTTP 拉取用 Node 内置 `http/https` 模块（零额外依赖） |

### 文件结构

```
cloudfunctions/importQuestionBank/
├── index.js        # 云函数入口（拉取编排 + 数据库写入）
├── lib.js          # 纯逻辑（HTTP 拉取/重试、提取、校验、组装、分批），可本地单测
├── mockSource.js   # 内置示例数据源（7 道题，覆盖四题型）
├── package.json    # 依赖 wx-server-sdk
└── config.json     # timeout=20 秒
```

---

## 二、触发方式

云函数可通过以下三种方式触发，**任选其一**：

### 1. 控制台手动触发（最简单，部署后立即验证）
微信开发者工具 →「云开发」控制台 →「云函数」→ `importQuestionBank` →「云端测试」，参数可留空（走内置示例数据源）。

### 2. 小程序端调用
```js
wx.cloud.callFunction({
  name: 'importQuestionBank',
  data: { /* 见下方入参，可省略 */ }
}).then(res => console.log(res.result));
```

### 3. 定时触发器（定期自动拉取）
在 `cloudfunctions/importQuestionBank/config.json` 中增加 `triggers` 字段（cron 表达式，7 字段，UTC+8）：

```json
{
  "permissions": { "openapi": [] },
  "timeout": 20,
  "triggers": [
    {
      "name": "importQuestionBankDaily",
      "type": "timer",
      "config": "0 0 3 * * * *"
    }
  ]
}
```

- 示例 `"0 0 3 * * * *"` = 每天凌晨 3 点触发。
- `*/5 * * * * * *` = 每 5 秒一次（仅测试用）。
- 注意：定时触发时函数的返回结果不会返回给调用方；微信可能重复推送，需依赖幂等去重（本函数已实现）。

## 三、入参（event，均可选）

| 参数 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `sourceUrl` | string | 否 | 数据源地址。不传则使用内置示例数据源 `mockSource.js` |
| `sourceName` | string | 否 | 数据源标识，写入 `questions.source` 字段（默认 `mock` 或 `http`） |
| `dryRun` | boolean | 否 | `true` 时只拉取+校验、不写库，用于预览数据源内容 |

调用示例：
```js
// 拉取真实数据源并写入
wx.cloud.callFunction({ name: 'importQuestionBank', data: {
  sourceUrl: 'https://example.com/api/questions',
  sourceName: 'partnerA'
}});

// 仅预览（不写库）
wx.cloud.callFunction({ name: 'importQuestionBank', data: { sourceUrl: 'https://example.com/api/questions', dryRun: true } });
```

## 四、数据源接口与数据格式

数据源接口需返回 **JSON**，支持以下四种结构之一（云函数会自动识别）：

```jsonc
// ① 题目数组
[ { "id": "q1", ... }, { "id": "q2", ... } ]

// ② 带 questions 字段
{ "questions": [ { ... } ] }

// ③ 带 data 字段
{ "data": [ { ... } ] }

// ④ 带 list 字段
{ "list": [ { ... } ] }
```

### 单条题目字段

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `id` | string | 否 | 数据源侧题目唯一标识，用于幂等去重（写入 `sourceId`）。建议提供，缺失则无法去重 |
| `subject` | string | 是 | 学科名（如「数学」），不存在则自动创建 |
| `knowledgePoint` | string | 是 | 知识点名（如「二次函数」），不存在则自动创建 |
| `difficulty` | number | 否 | 难度 1/2/3（默认 1） |
| `type` | string | 是 | `single` / `multiple` / `fill` / `solution` |
| `stem` | string | 是 | 题干 |
| `stemImage` | string | 否 | 题干配图（云存储 fileID 或 https） |
| `options` | array | 选择题必填 | `[{ "key": "A", "text": "..." }]` |
| `answer` | object | 是 | 标准答案（结构见下） |
| `analysis` | string | 否 | 解题思路总述 |
| `steps` | array | 否 | 分步解析 `[{ "order":1, "title":"...", "content":"..." }]` |
| `tags` / `source` | — | 否 | 标签 / 来源（可覆盖 sourceName） |

### `answer` 结构（按题型）

```jsonc
{ "keys": ["A", "C"] }                    // 单选/多选
{ "blanks": [["29"], ["x=1","x = 1"]] }   // 填空（多空、每空多等价答案）
{ "reference": "参考答案…", "keywords": ["配方","x=2"] }  // 解答题（无关键词则「待批改」）
```

## 五、返回结果

```jsonc
{
  "ok": true,
  "source": "mock",              // 数据源（mock 或 sourceUrl）
  "total": 7,                    // 拉取到题目总数
  "valid": 7,                    // 校验通过
  "invalid": 0,                  // 校验失败（详见 errors）
  "inserted": 7,                 // 新写入
  "skipped": 0,                  // 已存在（幂等去重跳过）
  "failed": 0,                   // 写入失败（详见 failedList）
  "createdSubjects": 2,          // 自动创建的学科数
  "createdKnowledgePoints": 5,   // 自动创建的知识点数
  "errors": [],                  // 校验失败明细（最多 20 条）
  "failedList": []               // 写入失败明细（最多 20 条）
}
```

## 六、错误处理与重试机制

| 场景 | 处理方式 |
|---|---|
| **HTTP 拉取失败**（非 200、超时、连接错误、重定向后失败） | 指数退避重试，默认最多 3 次（1s → 2s → 4s），全部失败则抛错终止。可在 `lib.js` 的 `DEFAULT_CONFIG` 调整 `maxRetries` / `baseRetryDelayMs` / `requestTimeoutMs` |
| **数据源格式无法识别** | 抛错终止，提示应为题目数组或含 `questions`/`data`/`list` 字段 |
| **单条题目校验失败** | 跳过该条，记录到返回的 `errors`，不影响其它题目写入 |
| **单条写入失败** | 捕获异常，跳过该条，记录到 `failedList`，继续写后续题目 |
| **重复题目（同 `sourceId`）** | 幂等去重，跳过，计入 `skipped`，不会重复写入 |
| **缺失学科/知识点** | 自动创建，无需人工预先建 |

> 幂等性：云函数遵循「无状态、幂等」原则（微信云开发要求）。重复调用不会产生重复题目——前提是数据源题目带有稳定唯一的 `id`（作为 `sourceId`）。

## 七、部署步骤

1. 在微信开发者工具中，右键 `cloudfunctions/importQuestionBank` →「上传并部署：云端安装依赖」。
2. 部署后在「云函数」页找到 `importQuestionBank`，确认状态为「运行中」，超时已按 `config.json` 设为 20 秒。
3. 首次验证：点「云端测试」，参数留空 → 应返回 `inserted: 7`（写入 7 道示例题）。
4. 再次「云端测试」→ 应返回 `inserted: 0, skipped: 7`（幂等去重生效）。

## 八、接入真实数据源

只需让数据源接口返回第三节所述 JSON 结构，然后：

```js
wx.cloud.callFunction({
  name: 'importQuestionBank',
  data: { sourceUrl: '你的数据源地址', sourceName: '你的数据源标识' }
});
```

接入时注意：

1. **字段映射**：若数据源字段名不同（如用 `content` 表示题干、`answers` 表示答案），可在 `lib.js` 增加一层字段映射，或要求数据源返回标准结构。
2. **外网访问**：云函数默认可访问公网；若数据源要求鉴权（API Key 等），在 `lib.js` 的 `httpGet` 中补充请求头。
3. **超时**：单次拉取 + 写入若超过 20 秒，可将 `config.json` 的 `timeout` 调大（最大 60 秒）。
4. **大批量**：单次云函数执行适合中小批量（数百~数千条）；更大批量建议分页拉取、多次触发，或拆分任务。
